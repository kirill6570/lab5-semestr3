# Лабораторная работа №5 — вариант 10

Короткевич Кирилл Олегович, АБ-522. Генерация HTML-отчётов с паттерном «Строитель».

## Visual Studio Code на Ubuntu

Откройте папку «Лаба№5». В меню «Терминал → Создать терминал» выполните:

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o lab5
./lab5
```

Ctrl+Shift+B собирает программу через подготовленную задачу VS Code. Для F5 нужны расширение Microsoft C/C++ и GDB. Запуск из терминала от них не зависит.

Выберите дисциплину, номер работы, тему, цель, задание, вывод и путь к скриншоту PNG/JPG. Автор и группа заданы в main.cpp. Путь вводите без кавычек; пустая строка означает отчёт без скриншота.

Результат: `generated/custom/report.html`. Откройте его в браузере. Папку `assets` храните рядом с HTML.

## Три демонстрационных документа

```bash
./lab5 --demo
```

Результаты находятся в `generated/discipline-1`, `discipline-2`, `discipline-3`. Это демонстрация генератора для трёх дисциплин, а не три выполненные лабораторные. Пример изображения — реальный снимок сформированного HTML. Его можно заменить в `assets/demo-preview.png`.

`./lab5 --demo my-reports` задаёт другой каталог. Запускайте программу из папки проекта: main.cpp и assets/uml.svg читаются по относительным путям.

## Структура паттерна

Report — продукт; ReportBuilder — абстрактный строитель; HtmlReportBuilder — конкретный строитель; Director — порядок сборки; LabData — данные. Директор работает через ссылку на абстрактный класс. Один HTML-строитель обслуживает три дисциплины, поскольку формат одинаков, меняются только данные.

Собираются титульный блок, цель, задание, UML, раскрываемый листинг, таблица, диаграмма, скриншот и вывод. В Word-отчёт по лабораторной код не включается по просьбе автора; ссылка на GitHub размещена в конце отчёта.

## Проверки

```bash
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
python3 tests/test_cli.py
```

Проверяются экранирование HTML, повторная сборка, независимость продукта, три дисциплины, наличие ресурсов, некорректный ввод и ошибки файлов. Тест CLI создаёт учебный отчёт в generated/custom.

Внешние библиотеки программе не нужны: используется стандартная библиотека C++17.
